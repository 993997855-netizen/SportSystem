# 永嘉南联青训云端管理版 V3

本项目以 `CharRic/SportSystem` 为底座，包含学员、固定班级成员、课程、请假、点名、课时流水、训练反馈，以及招生 CRM 与体验课转化闭环。

## 已实现

- 南联蓝金品牌首页、透明队徽、家长端课程页和运营驾驶舱。
- 三角色权限：管理员、教练、家长；本地模式可切换角色预览。
- 学员档案：家长、紧急联系人、健康备注、班级、课时余额。
- 逐节课程：日期、时间、场地、教练、训练重点、容量和发布状态。
- 家长报名：普通班低于标准人数时直接形成正式 `classMember`；达到标准人数后显示“本班已满”并停止自主报名。
- 管理员编班：标准人数仅作运营参考，达到或超过标准人数后二次确认，管理员仍可人工添加。
- 家长请假：提交原因；管理员审核；同意后仅把本节考勤改为请假并保持扣课 0 节，不改变班级成员。
- 球员成长 V4：日常训练评价、独立阶段测评快照、五维雷达图、历史趋势、比赛记录和成长时间轴。
- 南联周日成长联赛：赛季、周日轮次、单双周年龄排程、内外球队、固定比赛名单、循环对阵、比分与内部球员成长回流。
- 精英队选拔：成长数据只作为教练推荐与管理员审核的参考，系统不会按分数自动晋升。
- 手机点名：到课/缺勤扣1节，请假/伤病不扣；重复保存按差额校正。
- 不可覆盖的课时流水：建档、购课、到课扣减和状态校正均生成独立记录。
- 教练训练反馈：评分、能力标签、具体表现和下阶段建议。
- 续费闭环：南联套餐 `1380元/14节`、`1980元/28节`，管理员确认到账后事务加课。
- 运营后台：学员、固定班级成员、课程、待审请假、待确认续费、预警和审计记录。
- 云端关键流程覆盖班级成员、请假状态、点名扣课、续费加课和邀请码领取。
- 数据查询支持分页，不再受原PR `limit(100)` 影响。
- 招生中心：招生看板、全部/我的线索、待跟进、公海池、已成交和招生统计。
- CRM 线索：手机号重复检测、负责人分配、A/B/C 意向、完整跟进时间轴、归档和公海原子领取。
- 体验课：复用原有班级和逐节课程，占用课程容量但不进入正式报名、不扣课、不写正式课时流水。
- 体验课点名与六维反馈，完成后自动生成次日回访任务。
- 正式转换：复用原有学员建档和期初课时流水，同时保留来源、负责人、体验课与成交历史。

## 页面

原有15个页面保持不变；V3 新增招生看板、线索列表、线索表单、线索详情、跟进表单、体验课列表、体验课预约、体验课反馈、正式转换和招生统计，共25个业务页面。

## 直接预览

1. 使用微信开发者工具导入本目录。
2. `project.config.json` 已配置当前开发 AppID；如复制给其他主体使用，请替换为对应小程序 AppID。
3. 在“我的”页面切换管理员、教练员和家长视角。
4. 本地班级报名、请假、点名、课时流水和反馈会保存在微信本地缓存。
5. 点击“重置演示数据”可恢复初始状态。

本地业务逻辑不依赖云环境，但小程序项目能否在开发者工具中创建，仍由微信当前版本对 AppID 的校验规则决定。

## 启用云端共享

1. 把 `project.config.json` 的 `appid` 换成南联小程序 AppID。
2. 在 `miniprogram/app.js` 填入云开发环境 ID。
3. 在 `cloudfunctions/clubApi/v2.js` 的 `BOOTSTRAP_ADMIN_OPENIDS` 填入公司管理员 OPENID。
4. 部署 `cloudfunctions/clubApi`，选择“云端安装依赖”。
5. 创建集合与索引，并把所有业务集合权限设置为“仅云函数可读写”。
6. 管理员先完成初始化，再生成24小时有效的一次性邀请码绑定教练和家长。

详细配置见 [南联V3数据模型与上线清单](docs/南联V3数据模型与上线清单.md)。

## 自动化回归

```bash
node tests/crm-regression.js
```

该脚本覆盖18项关键检查，包括线索、重复检测、权限、跟进、公海领取、体验课容量、体验课点名不扣课、自动回访、正式转换、CRM关联和原有正式点名扣课。

## 当前边界

- 续费仍是申请和人工确认到账，不是微信支付。
- 请假截止时间、固定梯队自动排课、跨期课包有效期需要南联最终确认后参数化。
- 未包含合同签署、保险投保接口、订阅消息、退款、发票和财务对账。
- 正式录入未成年人信息前，需要完成隐私政策、监护人授权和数据留存制度。
- `quickstartFunctions` 是原仓库遗留示例，V2业务不使用它。
