# 永嘉南联青训云端管理版 V2

本项目以 `CharRic/SportSystem` 的 Draft PR `agent/football-club-mvp` 为底座，保留管理员、教练、家长三角色、学员班级、云函数鉴权与手机点名能力，并重构为适合南联俱乐部运营的课程与课时系统。

## 已实现

- 南联蓝金品牌首页、透明队徽、家长端课程页和运营驾驶舱。
- 三角色权限：管理员、教练、家长；本地模式可切换角色预览。
- 学员档案：家长、紧急联系人、健康备注、班级、课时余额。
- 逐节课程：日期、时间、场地、教练、训练重点、容量和发布状态。
- 家长报名：有名额直接报名，满员自动进入按时间排序的候补队列。
- 家长请假：提交原因；管理员/教练审核；同意后释放名额并自动转正最早候补。
- 手机点名：到课/缺勤扣1节，请假/伤病不扣；重复保存按差额校正。
- 不可覆盖的课时流水：建档、购课、到课扣减和状态校正均生成独立记录。
- 教练训练反馈：评分、能力标签、具体表现和下阶段建议。
- 续费闭环：南联套餐 `1380元/14节`、`1980元/28节`，管理员确认到账后事务加课。
- 运营后台：学员、课程、报名、候补、待审请假、待确认续费、预警和审计记录。
- 云端关键流程使用数据库事务：报名容量、请假状态、候补转正、点名扣课、续费加课和邀请码领取。
- 数据查询支持分页，不再受原PR `limit(100)` 影响。

## 页面

首页、课程列表、课程详情、课程发布、学员列表、学员详情、学员表单、班级列表、班级表单、逐节课程点名、续费管理、请假审核、训练反馈发布、运营后台和身份绑定，共15个页面。

## 直接预览

1. 使用微信开发者工具导入本目录。
2. 当前 `appid` 使用占位值 `touristappid`；部分新版开发者工具不再接受该值，遇到导入错误时需先换成南联正式 AppID 或微信提供的测试号 AppID。
3. 在“我的”页面切换管理员、教练员和家长视角。
4. 本地报名、请假、候补、点名、课时流水和反馈会保存在微信本地缓存。
5. 点击“重置演示数据”可恢复初始状态。

本地业务逻辑不依赖云环境，但小程序项目能否在开发者工具中创建，仍由微信当前版本对 AppID 的校验规则决定。

## 启用云端共享

1. 把 `project.config.json` 的 `appid` 换成南联小程序 AppID。
2. 在 `miniprogram/app.js` 填入云开发环境 ID。
3. 在 `cloudfunctions/clubApi/v2.js` 的 `BOOTSTRAP_ADMIN_OPENIDS` 填入公司管理员 OPENID。
4. 部署 `cloudfunctions/clubApi`，选择“云端安装依赖”。
5. 创建集合与索引，并把所有业务集合权限设置为“仅云函数可读写”。
6. 管理员先完成初始化，再生成24小时有效的一次性邀请码绑定教练和家长。

详细配置见 [南联V2数据模型与上线清单](docs/南联V2数据模型与上线清单.md)。

## 当前边界

- 续费仍是申请和人工确认到账，不是微信支付。
- 请假截止时间、固定梯队自动排课、跨期课包有效期需要南联最终确认后参数化。
- 未包含合同签署、保险投保接口、订阅消息、退款、发票和财务对账。
- 正式录入未成年人信息前，需要完成隐私政策、监护人授权和数据留存制度。
- `quickstartFunctions` 是原仓库遗留示例，V2业务不使用它。
