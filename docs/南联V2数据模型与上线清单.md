# 南联V2数据模型与上线清单

## 核心集合

| 集合 | 用途 | 关键字段 |
|---|---|---|
| `users` | 微信账号与角色 | `openid`、`role`、`studentIds`、`classIds` |
| `students` | 学员主档 | 监护人、紧急联系人、健康备注、课时汇总 |
| `classes` | 长期班级/梯队 | 教练、场地、固定学员 |
| `sessions` | 每一次真实训练 | 日期、时间、容量、状态、训练重点 |
| `enrollments` | 报名关系 | `sessionId`、`studentId`、`status` |
| `waitlist` | 候补队列 | 课程、学员、进入时间、转正状态 |
| `leaveRequests` | 家长请假申请 | 原因、审核状态、审核人、审核时间 |
| `attendance` | 实际出勤 | 课程、学员、状态、实际扣课数 |
| `lessonLedger` | 不可覆盖课时流水 | 增减值、变更后余额、关联业务、操作人 |
| `feedback` | 教练训练反馈 | 评分、标签、正文、课程与学员 |
| `renewals` | 续费申请 | 套餐、金额、状态、确认人 |
| `invites` | 身份邀请码 | 角色、绑定对象、有效期、使用状态 |
| `auditLogs` | 管理操作审计 | 操作人、动作、对象、时间、摘要 |

`students.remainingLessons` 是快速展示用的汇总值；任何变化必须同时产生 `lessonLedger`，不能从学员编辑页直接修改。

## 必建索引

- `users`: `openid` 唯一索引。
- `sessions`: `status + date`。
- `enrollments`: `sessionId + studentId + status`；生产环境应增加防重复约束。
- `waitlist`: `sessionId + status + createdAt`。
- `leaveRequests`: `status + sessionId`、`studentId + createdAt`。
- `attendance`: `sessionId + studentId` 唯一索引。
- `lessonLedger`: `studentId + createdAt`。
- `feedback`: `studentId + createdAt`、`sessionId + createdAt`。
- `renewals`: `status + createdAt`、`studentId + createdAt`。
- `invites`: `code + status`。
- `auditLogs`: `createdAt`。

## 权限原则

- 所有业务集合：前端不可直接读写，只允许 `clubApi` 云函数访问。
- 管理员：全部业务数据和配置。
- 教练：仅所带班级、对应课程、报名学员、点名和反馈。
- 家长：仅绑定孩子的档案、课时、反馈、报名、候补、请假和续费。
- 健康备注属于敏感未成年人信息，不进入通知文案、不出现在公开页面。

## 上线前必须完成

1. 替换管理员 OPENID 和小程序 AppID。
2. 配置云环境、集合权限与上述索引。
3. 确认请假截止时间和缺勤扣课规则。
4. 确认固定梯队课程由谁批量排入学员。
5. 导入真实学员前取得监护人授权，补齐保险、合同和紧急联系人。
6. 完成越权、重复提交、并发报名、重复点名和重复确认续费测试。
7. 配置云函数告警、日志保留、数据库备份和管理员交接机制。
8. 上线真实收款前补齐支付回调、退款、对账、发票和财务权限。
