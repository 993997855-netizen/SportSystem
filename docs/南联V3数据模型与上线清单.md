# 南联 V3 数据模型与上线清单

## V3 新增集合

| 集合 | 用途 | 关键字段 |
|---|---|---|
| `leads` | 潜在学员招生主档 | 孩子与家长资料、来源、状态、意向、负责人、跟进时间、转换关系 |
| `leadFollowUps` | 不可覆盖的跟进历史 | `leadId`、方式、结果、内容、下次时间、操作人、创建时间 |
| `trialBookings` | 体验课预约与反馈 | `leadId`、`classId`、`sessionId`、日期、状态、出勤、六维反馈、推荐班级 |

`students` 增加可选字段：`crmLeadId`、`source`、`school`、`grade`、`registrationDate`、`recruitmentOwnerId`、`recruitmentOwnerName`。历史学员不需要补齐这些字段，也不影响原有业务。

`sessions`、`enrollments` 和 `waitlist` 的数据结构不变。容量判断统一使用：

```text
正式报名人数 + 已预约体验课人数 < 课程容量
```

体验课出勤只更新 `trialBookings.attendanceStatus`，绝不写入 `attendance` 或 `lessonLedger`。

## 建议索引

- `leads`: `ownerCoachId + updatedAt`、`status + updatedAt`、`nextFollowUpAt`、`mobile`、`convertedStudentId`。
- `leadFollowUps`: `leadId + createdAt`、`nextFollowUpAt`。
- `trialBookings`: `sessionId + status`、`leadId + createdAt`、`trialDate + status`。
- 延续 V2 所有索引，尤其是 `enrollments(sessionId + studentId + status)`、`attendance(sessionId + studentId)` 唯一约束和 `waitlist(sessionId + status + createdAt)`。

## 权限与数据安全

- 所有集合设置为仅云函数可读写，前端不能直连数据库。
- 管理员可查看全量 CRM、分配、归档、公海管理、统计和正式转换。
- 教练仅查看自己的线索，可新增、跟进、预约、点名和填写体验课反馈；不能看公司统计或转换正式学员。
- 家长不能进入招生中心。
- 公海领取在云函数事务内检查并写入，避免多人同时领取。
- `auditLogs` 记录创建/修改线索、分配、公海、领取、归档、体验课创建/取消/反馈和正式转换。

## 云端启用步骤

1. 在 `cloudfunctions/clubApi/v2.js` 配置真实管理员 OPENID。
2. 在微信开发者工具中上传并部署 `clubApi`，选择云端安装依赖。
3. 确认 `leads`、`leadFollowUps`、`trialBookings` 已创建，并建立上述索引。
4. 将全部业务集合权限设置为仅云函数读写。
5. 用管理员进入“我的”生成教练邀请码，教练绑定后才能出现在负责人列表。
6. 先用本地演示模式走完一遍完整转化，再切到云端以一条测试线索复验。
7. 上线前备份数据库，并完成隐私政策、监护人授权、保险和紧急联系人流程。

## 演示数据

本地模式自动提供15条线索、3名负责人、至少8种来源、5条体验课记录，并覆盖新线索、已联系、已预约体验课、已体验、意向报名和已成交状态。点击“我的 → 重置演示数据”可随时恢复。

## 发布前回归

运行：

```bash
node tests/crm-regression.js
```

同时在开发者工具完成一次真机验证：新建线索 → 分配 → 跟进 → 预约体验课 → 课程点名 → 体验课反馈 → 次日回访 → 转正式学员 → 正式课程点名扣课。
