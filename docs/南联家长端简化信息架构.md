# 南联家长端简化信息架构

```text
首页
├─ 当前孩子（点击进入孩子资料，可切换或添加孩子）
├─ 下一次训练（查看课程 / 快速请假）
├─ 我的课程
│  ├─ 当前班级
│  ├─ 下一次训练 / 近期课程
│  ├─ 查看完整课表
│  └─ 班级报名
├─ 请假
│  └─ 最近可请假课程 → 我要请假
├─ 成长
│  ├─ 本次评价
│  ├─ 五维能力与进步趋势
│  ├─ 教练点评
│  └─ 查看全部测评
├─ 课时与购课
│  ├─ 当前孩子剩余课时
│  ├─ 购买课时
│  └─ 我的订单
├─ 周日联赛
└─ 俱乐部动态（弱化信息区）
```

教练简历、新闻、订单、完整课表、班级报名和孩子管理继续保留为二级入口或“我的”页面入口。
