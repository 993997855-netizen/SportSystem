# 南联 PHASE B：训练大纲与周训练计划恢复报告

## 一、阶段结论

PHASE B 已完成，并严格停在“训练大纲 + 周训练计划 + 单节训练重点”。本阶段没有继续恢复阶段测评、成长档案、精英选拔或赛事模块。

当前形成的业务闭环为：

```text
管理员维护训练大纲
→ 教练查看启用大纲
→ 教练为自己负责的班级制定周训练计划
→ 周会后确认计划与内部调整备注
→ 教练在具体课程中填写训练主题、训练重点和内部备注
→ 家长仅查看自己孩子所在班级课程的公开训练主题与重点
```

## 二、Restore Audit（旧代码恢复审计）

本阶段审阅了 2026-08-21 版本中的训练教研实现，并只恢复与当前正式模型兼容的部分。

### 冲突处理

- 旧版 `session.trainingFocus` 为数组，当前统一课表以字符串读取。本次统一写入字符串，例如 `变向 / 加速 / 射门`。
- `weeklyTrainingPlans.trainingFocus` 仍保留数组，便于周计划编辑和标签化展示。
- 旧版训练模块会接管 `getCoachWorkbench`。本次删除该路由，由现有统一课表系统继续负责教练工作台。
- 旧版演示日期为固定日期。本次新建周计划自动计算当前周一至周日。

## 三、功能实现

### 训练大纲

管理员可以：

- 新增、编辑大纲。
- 设置年龄组、普通班/精英队类型、训练主题、长期目标和说明。
- 使用 `sortOrder` 调整显示顺序。
- 停用或恢复大纲，历史数据不会删除。

教练只能查看 `active !== false` 的大纲，不能新增、修改、排序或停用大纲。

### 周训练计划

管理员可管理全部班级；教练只能管理 `user.classIds` 中自己负责的班级。

每条周计划包含：

- `classId`
- `coachId` / `coachName`
- `weekStart` / `weekEnd`
- `mainTheme` / `themeKey`
- `trainingFocus[]`
- `curriculumId`
- `status`：`DRAFT`、`CONFIRMED`、`COMPLETED`
- `meetingNote`：内部会议调整备注

同一班级、同一周不能存在两条未完成计划；教练创建计划时，后端强制使用当前教练身份。

### 单节训练重点

课程继续使用当前统一课表的数据结构：

- `trainingTheme`：字符串
- `trainingFocus`：字符串
- `trainingNote`：内部字符串
- `trainingThemeKey`
- `weeklyTrainingPlanId`

课程详情页增加“本节训练”展示；管理员和教练可进入“编辑训练重点”。发布/编辑课程页面也可直接填写训练主题、训练重点和内部备注。

## 四、权限和隐私

| 操作 | 管理员 | 教练 | 家长 |
| --- | --- | --- | --- |
| 查看训练大纲 | 全部（含停用） | 仅启用 | 不开放 |
| 维护训练大纲 | 可以 | 不可以 | 不可以 |
| 查看周训练计划 | 全部 | 自己负责班级 | 不开放 |
| 制定/确认周计划 | 全部班级 | 自己负责班级 | 不可以 |
| 编辑单节训练信息 | 全部课程 | 自己负责班级 | 不可以 |
| 查看公开训练主题/重点 | 可以 | 可以 | 仅自己孩子的有效班级课程 |
| 查看 `trainingNote` / `meetingNote` | 可以 | 授权班级可见 | 不可见 |

家长读取训练信息时，后端同时校验：

1. 学员确实归属于当前家长账号。
2. 学员在课程所属班级存在 `ACTIVE` 的 `classMembers` 记录。

家长接口不会返回 `trainingNote`、`meetingNote` 或完整周计划对象。普通课程详情的公开转换也会删除内部训练字段。
