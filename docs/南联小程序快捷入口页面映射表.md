## 其他入口来源

- “我的”页按当前角色读取 `PROFILE_FEATURES`，不缓存上一角色菜单。
- 运营后台读取 `OPERATIONS_FEATURES`，包含招生、训练、成长、测评、精英、联赛、发布课程、课程管理、总课表、教练课时、班级、学员、教练、账号、请假、套餐、订单、支付和新闻。
- 首页快捷入口统一使用 `openQuick → navigation.openFeature`；数据参数统一从 `event.currentTarget.dataset` 读取。
- `students` 与 `sessions` 是 TabBar 页面，不能直接携带 query，改用30秒内有效的一次性导航意图；直接点击 TabBar 会清除旧 mode。

## 合理复用白名单

| route | 区分方式 |
|---|---|
| `/pages/students/index` | 角色 + `directory / children / growth` |
| `/pages/sessions/index` | 角色 + `manage / attendance / classes / courses` |
| `/pages/classes/index` | 角色决定班级管理、我的班级或班级报名 |
| `/pages/coach-team/index` | 角色 + `mode=self` |
| `/pages/orders/index` | 角色 + `purchase / orders` |
| `/pages/growth-profile/index` | `studentId` + `growth / assessment` |
| `/pages/assessment-rounds/index` | 角色决定阶段测评或阶段评价 |
| `/pages/elite-selections/index` | 角色决定审核选拔或教练推荐记录 |
| `/pages/coach-workload/index` | 角色决定全体教练或本人课时 |

未列入 `ROUTE_REUSE_ALLOWLIST` 的重复 feature route 会被 `tests/navigation-route-regression.js` 判定为失败。
