# 南联教练端与家长端极简化调整报告

本轮只调整 COACH、PARENT 的入口层级、页面复用、任务路径和用户文案。ADMIN 首页仍保留 16 个入口；原页面、服务、API、数据结构及服务端权限模型均未删除或放宽。

## 二、COACH 教练端

最终一级入口为：

1. 今日教学
2. 我的班级
3. 学员成长
4. 推荐精英队
5. 我的工作

合并与降级关系：

- “我的课表 + 考勤 + 本人课程”合并到“今日教学”。课程卡片直接提供开始点名和课后记录；顶部提供今天、本周、全部切换。
- “我的班级 + 我的学员”合并到“我的班级”。班级详情继续进入学员名单和学员教学档案。
- “成长管理 + 阶段评价”统一为“学员成长”，新增评价成为成长页内操作。
- “我的课时 + 我的资料”合并为“我的工作”。仍只显示真实课时/工作量，不显示虚构收入金额。
- “周训练计划”降级为“今日教学”和“我的工作”中的二级入口。
- 新闻动态改为首页底部“俱乐部动态”，不再占据大快捷入口。

教练考勤路径由“首页 → 考勤 → 查找课程 → 点名”缩短为“首页 → 今日教学 → 开始点名”；当天下一节课程还可通过首页“进入课堂”直接进入。

阶段评价路径由独立的“阶段评价/成长管理”两个概念统一为“首页 → 学员成长 → 选择学员 → 新增评价”。

## 三、PARENT 家长端

最终一级入口为：

1. 我的课程
2. 请假
3. 成长
4. 课时与购课
5. 周日成长联赛

合并与降级关系：

- “我的班级 + 我的课程 + 我的课表”合并为“我的课程”。页面内同时显示当前班级、下一次训练、近期课程，并提供完整课表和班级报名入口。
- 多孩子家庭可在课程页按“全部孩子/单个孩子”查看，不串用班级或课程数据。
- “成长档案 + 阶段测评”统一为“成长”，阶段测评成为成长页内的切换操作。
- “课程套餐 + 我的订单 + 课时余额”合并为“课时与购课”，同页查看余额、购买课时和订单。
- “我的孩子”移出核心宫格；一个孩子时点击顶部孩子卡片进入资料，多孩子时继续使用孩子切换器。
- 教练员简历、班级报名、完整课表和订单保留为二级入口或“我的”入口。
- 新闻动态改为首页底部“俱乐部动态”。

请假页现在首先展示最近可请假的课程，家长可直接点击“我要请假”。常规路径由先找孩子、班级和课次的约 4 个操作层级，缩短为“首页 → 请假 → 我要请假”两个主要操作层级；首页下一次训练卡片也提供“去请假”。

## 四、首页与页面体验

- COACH 首页顶部增加“今天要做什么”，显示今日课程数及下一节课程。
- PARENT 首页顶部增加“下一次训练”，直接提供查看课程和请假动作。
- 首页统计卡仅保留给 ADMIN，避免教练和家长同时面对过多同级卡片。
- 班级技术编号不再向家长展示。
- 用户可见角色文案由“学员端”统一为“家长”。
- 保留现有 TabBar 架构，不新增复杂动态 TabBar；复用页面继续使用既有导航意图、mode 和标题机制。
