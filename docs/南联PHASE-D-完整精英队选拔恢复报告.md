# 南联 PHASE D：完整精英队选拔恢复报告

## 一、阶段结论

PHASE D 已完成本地恢复和增量适配。本阶段仅恢复完整精英队选拔，不进入 PHASE E 周日成长联赛。

正式流程：

```text
普通班正式学员
→ 授权教练观察成长数据
→ 教练填写目标精英队与推荐理由
→ 生成 PENDING 推荐记录
→ 管理员审核
→ 通过后创建精英队 ACTIVE classMember
```

成长分数只作为人工参考，不存在自动晋升。

## 二、Restore Audit

以上缺口均已修复。

## 三、角色能力

### 教练

- 只能推荐自己被授权班级中的 `ACTIVE` 正式成员。
- 填写目标精英队和推荐理由。
- 推荐后状态为 `PENDING`，不会立即编队。
- 只能查看自己提交的推荐记录。
- 可以在推荐页面查看授权学员的成长参考。
- 无权审核推荐。

### 管理员

- 查看全部推荐记录。
- 选择“确认入队”或“暂不入选”。
- 默认保留原普通班关系。
- 可明确关闭“保留原普通班”，将原班关系标记为 `INACTIVE`。
- 精英队达到标准人数后允许人工确认继续添加，不创建候补。
- 可以直接晋升，但仍会生成完整 `APPROVED eliteSelection` 审计记录。

### 家长

- 不能自行申请或报名精英队。
- 不能进入推荐与审核后台。
- 可以通过孩子班级资料看到是否已经属于精英队。

## 四、数据结果

审核通过后新增：

```text
classMembers
  classId = 目标精英队
  studentId = 学员
  memberType = ELITE
  status = ACTIVE
  source = ELITE_PROMOTION
  selectionId = 推荐记录
```

同时在 `playerGrowthEvents` 写入 `ELITE_PROMOTION`，用于成长时间线。

推荐、拒绝和通过记录永久保存在 `eliteSelections`；不会因后续操作覆盖历史。

## 五、页面与入口

- 管理员首页：精英队选拔。
- 教练首页：精英队推荐。
- 运营后台：精英队选拔。
- 普通班详情：管理员“晋升精英队”、教练“推荐进入精英队”。
- 精英队详情：管理员查看“推荐审核（数量）”。
- 推荐页面：成长参考、目标精英队、推荐理由。
- 审核页面：学员照片、来源班级、目标精英队、推荐理由、成长档案入口、审核操作。

新增注册页面：

- `pages/elite-action/index`
- `pages/elite-selections/index`

## 六、关键规则

1. 推荐不会创建 `classMember`。
2. 只有管理员审核通过才创建精英队成员关系。
3. 默认保留普通班；只有管理员明确选择才退出原班。
4. 成长分数不会自动晋升。
5. 精英队没有候补、补位或释放名额逻辑。
6. 精英队选拔不修改考勤和课时流水。
7. 家长不能通过接口直接报名精英队。
8. 教练不能跨授权班级推荐。
