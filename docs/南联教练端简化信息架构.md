# 南联教练端简化信息架构

```text
首页
├─ 今天要做什么（今日课程 / 下一节课 / 进入课堂）
├─ 今日教学
│  ├─ 今天 / 本周 / 全部
│  ├─ 查看学员
│  ├─ 开始点名
│  ├─ 查看训练重点
│  └─ 填写课后记录
├─ 我的班级
│  ├─ 搜索学员
│  ├─ 班级详情
│  └─ 学员教学档案
├─ 学员成长
│  ├─ 选择班级 / 学员
│  ├─ 最近评价与成长情况
│  └─ 新增评价
├─ 推荐精英队
│  └─ 选择班级 → 选择学员 → 推荐理由 → 提交
├─ 我的工作
│  ├─ 本月 / 累计课时
│  ├─ 本周训练计划
│  └─ 我的资料
└─ 俱乐部动态（弱化信息区）
```

底层课程、考勤、周计划、测评、成长、课时和教练档案能力全部保留。
