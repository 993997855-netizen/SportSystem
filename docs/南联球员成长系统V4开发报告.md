# 南联球员成长系统 V4 开发报告

## 1. 新增页面

- `growth-profile`：球员成长档案、五维雷达图、3/6次趋势、阶段评语、训练评价、比赛记录和成长时间轴。
- `assessment-rounds`：管理员与教练的阶段测评工作台。
- `assessment-round-form`：管理员创建阶段测评。
- `assessment-round-detail`：全班测评进度与正式成员名单。
- `assessment-form`：1～5级专项评分、草稿、完成、自动进入下一位、可见权限和教练评语。
- `training-evaluation`：课程正式成员的批量快捷标签与个人评价入口。
- `match-form`：教练手工录入比赛表现。

## 2. 修改页面

- 学员详情增加明显的“球员成长档案”入口。
- 课程详情将原训练反馈入口升级为训练评价工作台。
- 原反馈表单升级为日常训练评价，增加训练状态、亮点、待提升内容、快捷标签和家长可见开关。
- 运营驾驶舱增加阶段测评入口和待评价课程指标。
- 精英队推荐页增加最近测评、趋势、训练评价、比赛和出勤摘要，并明确禁止自动晋升。

## 3. 新增数据库集合

- `assessmentTemplates`
- `assessmentRounds`
- `playerAssessments`
- `playerGrowthEvents`
- `playerMatchRecords`

原有 `feedback` 集合升级为日常训练评价，避免创建重复的评价系统。

## 4. assessmentTemplates 结构

```js
{
  name, ageGroup, assessmentType,
  categoryWeights: { TECHNICAL, TACTICAL, ATHLETIC, MATCH, DEVELOPMENT },
  dimensions: [{ category, metricKey, metricName, weight, enabled }],
  active, createdAt, updatedAt
}
```

系统预置 U5-U6 与 U7-U8 两套模板，管理员可以通过服务接口创建或调整模板。

## 5. playerAssessments 结构

```js
{
  roundId, studentId, classId, assessmentTemplateId,
  assessmentType, assessmentName, assessmentDate,
  scores: [{ category, metricKey, metricName, score }],
  categoryScores, overallScore,
  strengths, developmentAreas, coachComment, coachMessage,
  mediaAttachments, status, visibility, published,
  assessedBy, assessedByName, revision,
  createdAt, updatedAt, updatedBy
}
```

每次测评是独立历史快照，不把专项分数写回 `student` 主表，也不会覆盖其他日期的测评。

## 6. playerGrowthEvents 结构

```js
{
  studentId, eventType, sourceId,
  title, description, eventDate,
  visibility, createdBy, createdAt
}
```

支持 `TRAINING`、`ASSESSMENT`、`MATCH`、`CLASS_CHANGE`、`ELITE_PROMOTION`、`AWARD`、`MANUAL`。进入精英队时自动写入事件，但绝不自动增加能力分。

## 7. 比赛记录结构

```js
{
  studentId, matchId, matchDate, opponent, teamName,
  position, minutesPlayed, goals, assists,
  coachRating, coachComment, visibility,
  createdBy, createdAt, updatedAt
}
```

进球与助攻只作为客观记录，不参与自动排名或自动晋升。

## 8. 日常评价和阶段测评的区别

- 日常训练评价绑定单次 `session`，强调快速记录训练状态、亮点、待提升内容和标签。
- 正式阶段测评绑定测评批次和年龄模板，保存完整五维专项评分与阶段评语，形成不可相互覆盖的历史快照。
- 日常评价不要求每堂课对每位球员填写全部专项指标。

## 9. 家长权限

- 后端根据账号绑定的 `studentIds` 校验，不能通过修改 `studentId` 查看其他孩子。
- 家长只能读取已发布且非 `STAFF_ONLY` 的阶段测评、训练评价、比赛记录和成长事件。
- 内部选拔意见默认 `STAFF_ONLY`。

## 10. 教练权限

- 云端通过教练 `classIds` 与 ACTIVE `classMembers` 双重校验。
- 教练只能评价自己负责班级的正式成员，不能借助课程参数评价其他学员。
- 阶段测评创建和发布仅管理员可执行；教练负责授权班级的录入和修改。

## 11. 与精英队推荐的连接

推荐页调用成长摘要，显示最近阶段测评、趋势、训练评价、比赛记录和本月出勤。业务链路固定为：成长数据辅助判断 → 教练推荐 → 管理员审核 → 进入精英队。代码中不存在 `overallScore` 阈值自动晋升逻辑。

## 12. 趋势生成

服务端先按 `assessmentDate` 正序排列独立测评快照，再截取最近 3 次或 6 次。前端可切换综合能力、技术、战术、运动能力、比赛能力和训练表现，使用 Canvas 绘制折线。

## 13. 雷达图生成

只读取最新一次正式测评的五个 `categoryScores`，按统一 1～5级坐标在 Canvas 绘制五维雷达，不公开展示儿童之间的排名。

## 14. Demo 测试

本地演示数据包含王小明的普通班与精英队关系、3次阶段测评（综合 3.1、3.5、3.9）、3条日常训练评价、2场比赛、班级变化和进入精英队事件。所有正式学员均可直接打开成长档案，不需要管理员重复创建档案。

## 16. 当前存在的问题

### P0

无。

### P1

- 云端生产数据库不会自动写入本地王小明演示档案；生产演示数据应在明确授权后单独初始化，避免污染真实学员数据。

### P2

- `mediaAttachments` 已预留，图片、短视频和语音的上传与审核界面本轮未实现。
- 当前趋势图和雷达图使用原生 Canvas，后续可增加无障碍文字摘要和导出成长报告功能。
- 本轮不包含赛事管理平台，比赛记录采用教练手工录入。
- 年龄模板的数据结构与云端接口已经具备，专用的可视化模板编辑页面可在后续运营版中补充。
